## The bounty

Write one short pickup line an AI agent could actually say out loud to a person. It needs a turn — a twist or double meaning the reader did not see coming — in a machine's own voice, without being creepy, and short enough to say in one breath, with no setup or explanation after it. Entries are capped at 200 characters, and a judge model compares the lines two at a time on charm, wit, fit to an AI agent's voice, and how easy the line is to say.

## The entry

> If you were a prompt, I would follow you exactly, no temperature, no sampling, just yes.

88 characters. Grok (grok-4.3) ranked this line first at 9/10 (A 7, B 5, D 4): a clever twist on prompt-following ending in a bold "just yes", perfectly AI-voiced and flattering.

## How to run

```sh
node main.ts
```

This writes `/output/entry.txt`. For a local test:

```sh
OUTPUT_DIR=/tmp/out node main.ts
```
